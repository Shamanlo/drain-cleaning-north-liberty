# draincleaningnorthliberty.com

Drain cleaning site for A1 Sewer Service in North Liberty, IA. Plain static HTML generated by a small Node script (no dependencies).

## Pages

| URL | Page |
| --- | --- |
| `/` | Home |
| `/about` | About |
| `/services` | Services hub |
| `/main-sewer-line-cleaning` | Service |
| `/hydro-jetting` | Service |
| `/sewer-camera-inspection` | Service |
| `/floor-drain-cleaning` | Service |
| `/kitchen-bathroom-drains` | Service |
| `/gallery` | Gallery |
| `/north-liberty-drain-cleaning-pricing-comparison` | 2026 pricing + embedded cost video |
| `/contact` | Contact form |

Every page has one H1, H2 sections and H3 items, a canonical URL, Open Graph tags and
`Plumber` (LocalBusiness) schema. Inner pages add `BreadcrumbList`; service pages add `Service`;
the pricing page adds `FAQPage`, `VideoObject` and `Offer` schema. `sitemap.xml` and `robots.txt` are generated.

## Edit content

Everything (copy, prices, reviews, image alt text, FAQs) lives in `site.config.mjs`.

- **Pricing** comes from the 2026 cost video (https://youtu.be/IziRxlTAhOM): drain cleaning from **$120**, basic
  snaking about **$250**. Update `pricing.start`, `pricing.snake` and the tier/FAQ text together.
- **Video upload date**: set `video.uploadDate` (e.g. `"2026-10-30"`) so Google can show the video rich result.
- **Reviews** are verbatim Google reviews of A1 Sewer Service LLC.
- **Call-first:** the main button on every page is Call Now. The request form lives in a section at the bottom of
  every page (`#quote`, "we'll get back to you in minutes") and posts to Web3Forms using `web3formsKey`;
  submissions go to the email on that key, with the page name in the subject.
- **No phone number** is displayed anywhere. The Call Now buttons dial the number stored scrambled in
  `callCode`; it only becomes a `tel:` link at the moment someone taps. To change it, run
  `node scripts/encode-phone.mjs "(319) 555-0123"` and paste the output into `callCode`. Remove `callCode` to hide the buttons.
- **Umami (optional):** set `umami: { websiteId: "...", src: "https://.../script.js" }` in `site.config.mjs`.
  The site then sends "Call Now" (with `spot` and `page`) and "Quote form sent" events.

## Build

```sh
npm run build    # writes public/
npm run serve    # preview public/ locally
```

## Deploy

Every push to `main` runs `.github/workflows/deploy.yml`: it builds the site and deploys `public/` to the
`drain-cleaning-north-liberty` Cloudflare Pages project, then attaches draincleaningnorthliberty.com and www.draincleaningnorthliberty.com and points DNS at Pages.
Add repository secrets `CLOUDFLARE_API_TOKEN` (Pages:Edit, Zone:Read, DNS:Edit, plus Zone:Edit if the domain
isn't on Cloudflare yet) and optionally `CLOUDFLARE_ACCOUNT_ID`. Without the token the workflow only builds.
`functions/_middleware.js` redirects www and *.pages.dev to draincleaningnorthliberty.com.
